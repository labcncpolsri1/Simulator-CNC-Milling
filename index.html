Simulator CNC Milling 3A

Simulator Mesin CNC 3A Emco 750 dengan Kontrol Siemens Sinumerik 840D sl / 828D.

PROGRAM DAN BENDA KERJA

Daftar pahat Z0 = permukaan atas benda. Nomor T cocok dengan T di program.
Subprogram (SPF) Isi nama L di atas tiap kolom (contoh L020). Akhiri dengan RET atau M17.

SIMULASI 3D AMAN

X 0.000
Y 0.000
Z 0.000
T -
S 0
F 0

Putar: seret. Zoom: scroll. Tombol Reset Kamera mengembalikan tampilan ke posisi awal. Jalur oranye = pemakanan, biru = gerak cepat. Warna permukaan: abu = belum terpotong, hijau = sudah dimakan (makin gelap makin dalam). Garis kuning = ukuran sebenarnya (mm), garis merah muda = kedalaman pahat, garis putih = kontur program (saat G41/G42, jalur pahat bergeser sebesar radius). Panah merah = sumbu X, hijau = Y, biru = Z. Kotak kecil di pojok kiri bawah menunjukkan arah X Y Z saat tampilan diputar. Corak halus di permukaan = jejak feed per gigi, kontrasnya diperbesar agar terlihat.

GAMBAR 2D HASIL AKHIR (DIMENSI)

Dibuat dari bentuk benda setelah seluruh program selesai, jadi tidak perlu menekan Cycle Start. Garis biru = ukuran (mm). Garis merah = titik nol (X0 Y0) dan garis potongan A-A, B-B. Nomor merah = area yang dimakan, rinciannya ada di tabel.
